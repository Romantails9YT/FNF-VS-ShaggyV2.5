Combined Mode (Starter)

This combined mode loader activates the Shaggy Ultimate Update as the base game. If you clicked LINK on the launcher, the base game's Freeplay will be augmented with selected songs from Shaggy X Matt (power, link, revenge, final_destination).

How this works:

  1. If you clicked LINK on the launcher, a flag fnf_combined_mode=1 is stored in localStorage.
  2. Open the Shaggy Ultimate Update (base) using the button below. The base game will check that flag and try to fetch extra song metadata files from ./combined/songs-data.json and merge them into Freeplay at runtime.
Open Shaggy Ultimate Update (base) Open Shaggy X Matt

Note: This is a safe starter implementation. If you want a full merge (C2 automatic merging of assets), confirm and I will read the mod folders, copy any missing audio/data files into combined/ and attempt to patch the base game's loader to include the additional songs directly.
